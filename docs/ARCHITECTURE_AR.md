# المعمارية المقترحة

## الافتراضات

- مجلد العمل الحالي هو جذر المشروع.
- MySQL هو خيار التشغيل الحالي، وSQLite مسموح فقط للتطوير والاختبارات الخفيفة.
- جمع الرسائل النصية فقط قابل للإعداد عبر `TUC_TELEGRAM_COLLECT_TEXT_MESSAGES` والقيمة الافتراضية `false`.
- التصنيف يجب أن يفضل `unclassified` عند الشك بدلا من التخمين.
- النظام لا يعتمد على أي خادم أو API مخفي؛ كل الخدمات الخارجية يجب أن تكون قابلة للإعداد.

## مسار البيانات

تيليجرام -> جامع الرسائل -> التحقق من الحالة التدريجية -> تحميل الملف المؤقت -> حساب SHA-256 -> منع التكرار -> استخراج النص أو OCR -> تنظيف النص -> التصنيف والتحقق -> التخزين المنظم -> قاعدة البيانات -> التقرير.

## الوحدات

- `app/config`: إعدادات البيئة وملفات YAML.
- `app/logging`: تسجيل منظم مع حجب الأسرار.
- `app/telegram`: تسجيل الدخول، العميل، الجمع، FloodWait، ومعدل الطلبات.
- `app/ingestion`: تحليل الرسائل، التحميل، التجزئة، ومنع التكرار.
- `app/processing`: استخراج PDF، OCR، تنظيف النص، والتصنيف.
- `app/database`: SQLAlchemy، الجلسات، النماذج، والمستودعات.
- `app/storage`: أسماء الملفات الآمنة ومسارات التخزين النهائية.
- `app/reports`: حساب تقارير التشغيل.
- `app/cli`: أوامر التشغيل.

## مخطط قاعدة البيانات المقترح

- `channels`: بيانات القناة، اسمها، معرف تيليجرام، حالتها، وآخر رسالة ناجحة.
- `messages`: الرسائل المجموعة مع قيد فريد على `(channel_id, telegram_message_id)`.
- `files`: بيانات الملفات، SHA-256، الحالة، النوع، الحجم، ومسار التخزين.
- `classifications`: نتيجة التصنيف، كود المادة، نوع المحتوى، الأدلة، وإصدار المصنف.
- `processing_runs`: بداية ونهاية التشغيل وعدادات النجاح والتكرار والفشل.
- `processing_logs`: سجل مراحل المعالجة لكل ملف.

## اعتماديات النظام على Ubuntu

- Python 3.12+
- MySQL
- Tesseract OCR
- حزمة اللغة العربية `tesseract-ocr-ara`
- Redis عند تفعيل العمال غير المتزامنين

## المخاطر الرئيسية

- تسجيل دخول تيليجرام يجب أن يتم مرة واحدة على VPS نفسه وعدم نقل ملف الجلسة.
- FloodWait يجب احترامه بالكامل دون أي محاولة للالتفاف على حدود تيليجرام.
- OCR العربي قد يكون بطيئا أو ضعيف الجودة في الملفات رديئة المسح؛ الفشل يجب أن يسجل ولا يوقف التشغيل.
- الملفات الكبيرة لا يجب إرسالها كاملة إلى نموذج AI؛ يجب قص النص أو تلخيصه بطريقة مضبوطة.
- التصنيف الآلي قد يخطئ، لذلك يجب التحقق من المادة والنوع والثقة والأدلة قبل قبول النتيجة.
