# جامع وتصنيف محتوى تيليجرام الجامعي

هذا المشروع يهدف إلى جمع الملفات التعليمية من قنوات تيليجرام المصرح بها، ثم تجهيزها لاستخراج النصوص، وتشغيل OCR عربي عند الحاجة، وتصنيف المحتوى حسب المادة ونوع المحتوى، وتخزين النتائج وإصدار التقارير.

## الحالة الحالية

تم تنفيذ نسخة محلية قابلة للاختبار تشمل:

- هيكل المشروع الأساسي.
- إعدادات البيئة باستخدام `.env`.
- تحميل ملفات `channels.yaml` و `subjects.yaml` والتحقق منها.
- قيم ثابتة لأنواع المحتوى المسموحة.
- تسجيل منظم بصيغة JSON مع حجب الحقول الحساسة.
- أوامر CLI فعلية: `health-check` و`init-db` و`telegram-login` و`collect` و`process` و`report`.
- تسجيل دخول تيليجرام عبر Telethon مع جلسة محفوظة محليا.
- جمع تدريجي حسب آخر رقم رسالة لكل قناة.
- تحميل ملفات آمن، حساب SHA-256، ومنع التكرار قبل المعالجة المكلفة.
- قاعدة بيانات SQLAlchemy مع Migration أولي.
- استخراج نص PDF وOCR عربي عند الحاجة.
- مصنف قابل للاستبدال مع تحقق صارم يمنع اختراع مادة أو نوع محتوى.
- تخزين منظم في `storage/processed` أو `storage/unclassified`.
- تقارير بعدادات الحالات والتوزيع حسب المادة ونوع المحتوى.
- قفل تشغيل لمنع تداخل أوامر cron.
- واجهة ويب كاملة مرتبطة بالباك لإدارة القنوات والمواد والرسائل والملفات والتصنيفات والتشغيلات وتشغيل demo.
- اختبارات وحدة تغطي المنطق الحرج بدون اتصال حقيقي بتيليجرام أو OpenAI.

العنصر الوحيد غير الممكن التحقق منه داخل بيئة العمل الحالية هو الاختبار الحي على قناة تيليجرام مصرح بها؛ يجب تنفيذه على VPS بعد تسجيل الدخول الحقيقي.

## شرح الملفات المهمة

- `app/config/settings.py`: يقرأ إعدادات التشغيل من متغيرات البيئة ويحدد المسارات والقيم الافتراضية الآمنة.
- `app/config/loaders.py`: يقرأ ملفات YAML الخاصة بالقنوات والمواد ويتأكد من صحة البنية.
- `app/logging/setup.py`: يضبط التسجيل المنظم ويخفي القيم الحساسة مثل كلمات المرور والجلسات والمفاتيح.
- `app/cli/commands.py`: يحتوي أوامر سطر الأوامر الفعلية للجمع والمعالجة والتقرير وتسجيل الدخول.
- `app/database/models.py`: نماذج قاعدة البيانات للقنوات والرسائل والملفات والتصنيفات والتقارير.
- `app/telegram/collector.py`: يجمع الرسائل الجديدة تدريجيا ويحمل الملفات ويفحص التكرار.
- `app/processing/pipeline.py`: يشغل استخراج النص وOCR والتصنيف والتخزين النهائي.
- `app/reports/reporter.py`: يحسب تقرير الحالة والتوزيع حسب المواد وأنواع المحتوى.
- `deploy/cron.example`: مثال cron يستخدم `flock` لمنع التداخل.
- `deploy/*.service` و`deploy/*.timer`: أمثلة systemd للتشغيل الدوري.
- `config/channels.yaml`: مثال لقنوات تيليجرام التي سيتم جمع المحتوى منها.
- `config/subjects.yaml`: المواد المسموحة للتصنيف. لا يسمح للنظام باختراع كود مادة خارج هذا الملف.
- `.env.example`: مثال للإعدادات المطلوبة بدون أسرار حقيقية.
- `.gitignore`: يمنع رفع الأسرار والجلسات وقواعد البيانات المحلية والملفات المؤقتة إلى Git.
- `tests/unit/`: اختبارات المنطق الحرج بدون اتصالات خارجية.
- `tests/integration/`: اختبارات تكاملية خفيفة لأوامر CLI باستخدام SQLite مؤقتة.

## التشغيل المحلي

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
python -m app.cli health-check
pytest
```

## أوامر التشغيل

```bash
python -m app.cli health-check
python -m app.cli init-db
python -m app.cli telegram-login
python -m app.cli collect --channel database --limit 5
python -m app.cli process
python -m app.cli report
python -m app.cli serve --host 127.0.0.1 --port 8000
```

داخل الواجهة يوجد زر `Seed Demo` لإنشاء بيانات تجربة في MySQL، ثم يمكنك رؤية الجداول والتقارير بدون تسجيل دخول تيليجرام.

Docker اختياري. يمكنك تشغيل MySQL محليا مثل Homebrew على macOS، أو تشغيله عبر
`docker compose up -d mysql redis` لو عايز بيئة معزولة للعرض.

في الإنتاج استخدم:

```bash
alembic upgrade head
```
